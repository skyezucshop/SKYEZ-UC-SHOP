# Skyez UC Shop

Готовый статический сайт для размещения в общем доступе.

## Быстрый запуск

1. Загрузите `index.html`, `styles.css` и `script.js` в один репозиторий GitHub.
2. Включите GitHub Pages.
3. Перед публикацией откройте `script.js` и замените `—` на ваши реальные цены в массиве `PACKS`.

Сайт не требует сервера или базы данных: оформление заказа собирает данные в браузере и открывает Telegram с готовым сообщением для `@skyezq`.

## Важно

Не просите у клиентов пароль, SMS-коды или коды двухфакторной аутентификации.
